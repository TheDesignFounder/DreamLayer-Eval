## Portability and distribution

Local runs used Intel macOS. The workflow in `.github/workflows/research.yml`
configures Linux/macOS with Python 3.11/3.12, frontend checks and Linux Playwright.
It also checks that native Windows is explicitly rejected. The workflow passed
actionlint 1.7.12 locally (shellcheck integration disabled). **Hosted CI has not
been executed in this local archive**; green hosted checks are required before
claiming those runner combinations passed. A Linux container runtime was unavailable
locally. Native Windows execution remains unsupported.

The research package is 1.1.0, record/bundle schema is 1, and SQLite migration
version is 2. See [compatibility and migrations](research-schema.md). Distribution
checks include an isolated wheel install and CLI replay, not only a successful
build. The [release summary](validation/current.json) records those results.

## Remaining verification limits

The live smoke verifies only the named model snapshots on small image fixtures
using the sparse one-pass protocol. Video and two-pass judging, rate limits,
timeouts, retries and reconciliation were not deliberately exercised against paid
APIs; failure handling retains its offline test coverage. Five offline tests also
verify the smoke guard and adapter/replay wiring.
Model-based ComfyUI generation, VQAScore, DINO, LPIPS, I3D
inference and migration of an original historical runtime database remain
unverified. The fifth independent review confirmed the ambiguous-provenance behavior
using its own fixture, including all four retry/upgrade flag combinations.

A passing smoke test establishes that a chosen configuration executed; it does not
validate a full study, scientific conclusions, prompt-injection resistance or
provider behavior across model updates. Keep study-specific budgets, versions,
assumptions and limitations with its exported evidence.
